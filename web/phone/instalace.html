Instalace

Co budeš potřebovat: mini-server (Raspberry Pi 4/5, nebo cokoli s Dockerem), USB modem, svoji SIM kartu, Lightning peněženku (Phoenix, Zeus, Alby, LNbits…) a ~hodinu času.

1. Krabička

A) umbrelOS (doporučeno — Raspberry Pi i x86):

  1. V umbrelOS otevři App Store → ⋯ → Community App Stores → vlož https://it-one.cz/git/Eddie/umbrel-store → Add.
  2. Nainstaluj appku GSM2SIP.
  3. Zapoj USB modem se SIM a otevři appku — o zbytek se postará sama.

B) Obecný Docker (jakýkoli Linux):

git clone https://it-one.cz/git/21/Gsm2Sip && cd Gsm2Sip
mkdir -p data/{smsdata,spool,astlog,ts-state}
WEBUI_PASSWORD=silne-heslo docker compose -f docker-compose.standalone.yml up -d

Web rozhraní krabičky pak běží na http://adresa-serveru:8090.

2. Privátní síť

  1. V Můj účet se přihlas Lightning peněženkou, zaplať předplatné a dej Přidat zařízení — dostaneš jednorázový klíč (platí 24 h, zobrazí se jen jednou).
  2. Klíč vlož ve web rozhraní krabičky na záložce Síť → Připojit. Za chvíli tam uvidíš adresu krabičky v privátní síti.

3. Telefon

  1. Nainstaluj aplikaci Tailscale (Google Play, nebo přes Obtainium; verzi z F-Droidu ne — má chybu s vlastním serverem). V ní: Settings → Accounts → ⋯ → Use an alternate server → zadej https://cockscale.twentyone.cz → potvrď v prohlížeči peněženkou. Tím je telefon ve tvé privátní síti.
  2. Nainstaluj aplikaci Linphone a zadej do ní přihlašovací údaje ze záložky Síť web rozhraní krabičky (uživatel, heslo, adresa serveru, transport UDP).
  3. Hotovo — voláš a píšeš ze svého čísla odkudkoli. Důležité pro Android: nepoužíváme Google push notifikace (žádný Google prostředník mezi tebou a tvým telefonem) — aplikace proto musí smět běžet na pozadí. Nastav Linphone i Tailscale v systému na Baterie → Neomezeno, jinak tě hovor nemusí dozvonit.

Soukromí

Koordinační server privátní sítě nutně vidí veřejné IP adresy tvých zařízení (jinak se nenajdou) a čas připojení — nikdy obsah hovorů ani zpráv, ten jde šifrovaně mezi telefonem a krabičkou. A protože nemáme žádnou tvoji identitu (žádné jméno, e-mail ani telefonní číslo), samotná IP adresa u nás k identifikaci osoby nevede. Po zrušení účtu data mažeme.

Na co pozor: hovory a SMS jdou z tvé krabičky do běžné mobilní sítě přes tvého operátora — úplně stejně, jako bys volal z obyčejného telefonu. Operátor je vidí a podléhají zákonnému odposlechu. Tahle služba chrání cestu mezi tebou a tvou krabičkou, ne mobilní síť za ní.

Aplikace třetích stran mají vlastní telemetrii: u Tailscale appky doporučujeme zablokovat doménu log.tailscale.io (privátní DNS/blokátor) — krabička má telemetrii vypnutou už z výroby. Všechno je open source — ověř si nás.
