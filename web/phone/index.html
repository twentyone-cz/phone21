Phone 21

Tvoje SIM karta doma na tvém serveru. Hovory a SMS z tvého čísla kamkoli na světě — přes privátní šifrovanou síť, bez účtů a bez odposlouchávatelných prostředníků.

Jak to funguje

Do svého serveru (Raspberry Pi s umbrelOS, nebo cokoli s Dockerem) zapojíš USB LTE modem se svojí SIM. Brána promění mobilní síť v SIP: na telefonu pak v aplikaci Linphone voláš a píšeš ze svého čísla — z domu, z ciziny, z mobilních dat. Telefon a brána se najdou přes naši privátní síť — bez veřejné IP, bez port forwardu, bez registrace.

📞 Hovory obousměrněPříchozí i odchozí, včetně VoLTE (automatická volba carrier profilu modemu). Zmeškané hovory ti přijdou jako zpráva do chatu.
💬 SMS v chatuPříchozí i odchozí SMS jako konverzace v Linphone, s potvrzenkami a spolehlivým doručením přes frontu, i když jsi zrovna offline.
🔒 Soukromí předevšímŽádné účty, žádný e-mail. Identita = klíč z Lightning peněženky. Provoz šifrovaný end-to-end, koordinační server vidí jen to minimum, bez kterého to nejde.
⚡ Platba LightningemPrivátní síť se platí bitcoinem přes Lightning — anonymně, bez karty, bez faktury. Vlastní hardware je tvůj, jednou provždy.

Instalace

A) umbrelOS (Raspberry Pi 4/5 nebo x86):

  1. V umbrelOS: App Store → ⋯ → Community App Stores → vlož https://it-one.cz/git/Eddie/umbrel-store → Add.
  2. Nainstaluj appku GSM2SIP z „Eddie Apps".
  3. Zapoj USB LTE modem (výrobce modem) se SIM kartou a otevři appku.

B) Obecný Docker (jakýkoli Linux):

git clone https://it-one.cz/git/21/Gsm2Sip && cd Gsm2Sip
mkdir -p data/{smsdata,spool,astlog,ts-state}
WEBUI_PASSWORD=silne-heslo docker compose -f docker-compose.standalone.yml up -d

Připojení telefonu

  1. V Můj účet se přihlas Lightning peněženkou (Phoenix, Zeus, Alby…), zaplať předplatné a dej Přidat zařízení → klíč vlož do web UI brány (záložka Síť).
  2. Na telefonu nainstaluj Tailscale (Play/Obtainium) → Use an alternate server → https://cockscale.twentyone.cz → potvrď v prohlížeči peněženkou.
  3. Nainstaluj Linphone a zadej SIP údaje ze záložky Síť web UI brány. Hotovo — voláš ze svého čísla odkudkoli.

Poctivé limity

Potřebuješ vlastní hardware (server + podporovaný USB modem + SIM) a ~hodinu času. Koordinační server privátní sítě nutně vidí veřejné IP tvých zařízení (bez toho se nenajdou) — nikdy ale obsah hovorů ani zpráv; data po zrušení mažeme. Klientské aplikace třetích stran (Tailscale, Linphone) jsou open source — návod obsahuje kroky, jak vypnout jejich telemetrii.
